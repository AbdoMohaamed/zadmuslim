# زاد المسلم • رفيق طاعاتك اليومية وصدقة جارية 🌿🤲

التنقل المعتمد للويب والهاتف: `index.html` للرئيسية، `services.html` للأقسام، و`settings.html` للإعدادات. ملف `app.html` مجرد تحويل للروابط القديمة ولا يحتوي واجهة مستقلة. ملف `assets/js/app.js` هو منطق مشترك للرئيسية والخدمات ويظل مطلوبًا.

تطبيق وموقع إسلامي شامل، تفاعلي وسريع جداً، مبني باستخدام أحدث تقنيات الويب **HTML5, CSS3, Vanilla JavaScript, Swiper.js, Firebase, PWA**، صُمم ليكون صدقة جارية ودعاءً مستمراً لروح فقيدنا الغالي (جدّي رحمه الله) وموتى المسلمين جميعاً، وملبياً لجميع احتياجات المسلم اليومية.

---

## ✨ المميزات الرئيسية للموقع:

### 1. 📖 القرآن الكريم والمصحف التفاعلي:
- عرض صفحات المصحف الشريف بدقة عالية مع التفسير الميسر لكل صفحة.
- مشغل تلاوات خاشعة وتلاوات لأشهر القراء.
- محرك بحث فوري في آيات وسور القرآن الكريم.
- نظام الختمة الجماعية المشتركة وحجز الأجزاء لروح المتوفى.

### 2. 🕌 مواقيت الصلاة وبوصلة القبلة الذكية (3D Qibla Compass):
- مواقيت الصلاة الدقيقة حسب موقع المستخدم (GPS أو اختيار المدينة).
- بوصلة تفاعلية لتحديد اتجاه الكعبة المشرفة وحساس الاتجاه للهواتف.
- تنبيه الأذان بصوت الحرم المكي الشريف.

### 3. 📜 الأربعون النووية كاملة (42 حديثاً):
- نصوص الأحاديث كاملة بالتشكيل ورواة الأحاديث.
- الشرح الميسر والفوائد التربوية والإيمانية لكل حديث.
- تلاوات صوتية لكل حديث مع إمكانية البحث والتصنيف والنسخ والمشاركة.

### 4. ✨ مكتبة أسماء الله الحسنى الـ 99:
- بطاقات تفاعلية أنيقة لأسماء الله الحسنى مصنفة (جلال، رحمة، قدرة، رزق، مغفرة، علم، حكمة).
- شرح معنى كل اسم، ودلالته الإيمانية، وكيفية الدعاء به لنيل البشارة النبوية.

### 5. 🌙 مواسم الطاعات والتقويم الهجري:
- تقويم هجري ومناسبات إسلامية مع عد تنازلي حيّ (رمضان، يوم عرفة، عيد الأضحى، عاشوراء، الأيام البيض).
- تتبع صيام السنن وأدعية الإفطار.

### 6. ⚖️ دليل أحكام الجنائز والصدقة الجارية:
- إجابات وفتاوى شرعية موثقة حول ما ينفع الميت (الدعاء، الصدقة، الحج والعمرة، قضاء الصيام والديون، آداب زيارة القبور).

### 7. 🖼️ صانع بطاقات وحالات واتساب/إنستغرام:
- توليد صور عالية الدقة بأبعاد متعددة: **حالة/ستوري (9:16)**، **بطاقة عمودية (4:5)**، **منشور مربع (1:1)**.
- سمات وألوان متعددة (الكحلي الملكي، الزمردي، العنابي، الرخامي).
- إمكانية التخصيص باسم المتوفى والدعاء، مع تحميل فوري PNG ومشاركة مباشرة.

### 8. 🎁 روابط صدقة جارية مخصصة للإهداء:
- إمكانية أن ينشئ أي زائر رابطاً مخصصاً لفقيده العزيز باسمه وصلة قرابته ومشاركته مع الأهل والأصدقاء لنيل الأجر.

### 9. 🔔 نظام التنبيهات والإشعارات الذكية (Push Notifications):
- تذكير بأذكار الصباح والمساء، أذكار النوم، سورة الكهف يوم الجمعة، صيام السنن، والتنبيه قبل الأذان.

### 10. 📿 السبحة الإلكترونية والأذكار وحصن المسلم:
- عداد تسبيح ذكي مع نغمات واهتزاز خفيف، وعداد إجمالي موحد للتسبيحات.
- أذكار الصباح والمساء، أذكار الصلاة، النوم، الاستيقاظ، وأدعية نبوية مصنفة.

### 11. 📻 إذاعة القرآن الكريم المباشرة 24/7:
- بث مباشر لإذاعة القرآن الكريم من القاهرة ومحطات إسلامية متعددة مع مشغل عائم.

### 12. 📱 تطبيق هاتف تقدمي (PWA) يدعم القراءة والأذكار دون إنترنت بعد تنزيل الموارد:
- قابل للتثبيت على الأجهزة والمتصفحات الداعمة. البث المباشر والخدمات السحابية تحتاج إلى الإنترنت؛ التنزيلات توضّح الموارد المتاحة محليًا.
